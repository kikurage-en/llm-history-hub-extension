# LLM History Hub

> English: [README.en.md](./README.en.md)

ChatGPT / Claude / Gemini / GoogleAI / Grok / X内Grok のチャット履歴を横断管理する Chrome 拡張（Manifest V3）。各サービスの履歴 API / DOM から会話 ID・タイトル・更新時刻を取得し、サイドパネルで一覧・検索・フィルタを提供します。

## 機能

- **6 サービス対応**: ChatGPT / Claude / Gemini / GoogleAI / Grok / X内Grok
- **サイドパネル UI**: ブラウザに常駐表示、可変幅
- **検索・フィルタ**: 期間・サービス・アカウント・お気に入りで絞り込み
- **エクスポート / インポート**: JSON / CSV 形式
- **多言語対応**: Chrome の UI 言語に応じて日本語 / 英語を自動切替

## 動作要件

- Google Chrome 114 以上（Side Panel API が必須）

## インストール

### 開発者モードで読み込み（unpacked）

1. このリポジトリをクローン、または GitHub Releases から zip をダウンロードして解凍
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本リポジトリのルートディレクトリ（または解凍したフォルダ）を選択
5. ツールバーの拡張機能アイコンをクリック → サイドパネルが開きます

## 基本的な使い方

### 1. サイドパネルを開く

ツールバーの拡張機能アイコンをクリックすると、ブラウザ右側にサイドパネルが開きます。サイドパネルは可変幅で、左右の境界をドラッグして幅を調整できます。

### 2. 履歴を同期する

各 LLM サービス（ChatGPT / Claude / Gemini / GoogleAI / Grok / X内Grok）に**事前にログイン**しておく必要があります。

1. ヘッダーの **同期** ボタンをクリック
2. ダイアログでサービスを選択（「全て」または個別チェック）
3. **同期** で実行

各サービスのタブが未開のまま同期したサービスは、エラー行に「タブで開いてから再同期してください」と誘導が表示されます。誘導アクションのリンクをクリックすると該当サービスを新しいタブで開けます。

### 3. 履歴一覧を見る

履歴は日付グループでまとめて表示され、サービス別に左端のアクセント色で識別できます（ChatGPT 緑 / Claude オレンジ / Gemini 青 / GoogleAI 紫 / Grok 黒 / X内Grok 黒）。各行には **タイトル**、**サービス**、**アカウント識別子**、**最終更新日時** が表示されます。

- **行をクリック**: 元の会話ページを新しいタブで開く
- **URL コピー** ボタン: 会話の URL をクリップボードへコピー
- **♥ ボタン**: お気に入りに追加 / 解除
- **`⚠ 別アカウント` バッジ**（黄色背景）: 現在ログイン中のアカウントとは異なるアカウントで取得された履歴

### 4. 検索・フィルタ

- **検索ボックス**: タイトル部分一致
- **日付範囲フィルタ**: プリセット「全期間 / 7日 / 30日」または `from / to` の日付指定
- **サービス chip**: `All` / `♥` / 各サービスで絞り込み（複数選択不可、AND ではなく単一選択）
- **アカウント select**: 同じサービス内で複数アカウントを使い分けている場合の絞り込み
- **並び替えトグル**（更新日 ▼/▲）: 降順 / 昇順を切替

検索・フィルタは AND で結合されます。chip / アカウント select の右肩には現在のフィルタ条件で絞り込まれた件数バッジが付きます。

### 5. お気に入り

各行の **♥** ボタンで ON / OFF。`♥` chip でお気に入りのみに絞り込み。お気に入り状態は同期実行時に保持され（既存の ♥ は同期で消えない）、JSON エクスポートに含まれるため、エクスポート→インポートで他環境に移行できます。

### 6. エクスポート / インポート

サイドパネル右上の **⋯ メニュー** から:

- **JSON エクスポート** / **CSV エクスポート**: 現在のフィルタ条件に関係なく全件
- **JSON インポート**: ファイル選択 → 既存と同じ `service` / `accountEmail` / `conversationId` の組は `updatedAt` が新しい方で上書き

### 7. 履歴の削除

ヘッダーの **削除** ボタン → ダイアログでサービスを選択 → **削除** で実行。「全て」を選択すると全データを削除します。**取消不可**です。

## 必要権限

| 権限 | 用途 |
|---|---|
| `tabs` | 同期対象タブの判定（履歴取得時のみ参照） |
| `sidePanel` | サイドパネル UI の提供 |
| `https://chatgpt.com/*` | ChatGPT 履歴 API へのアクセス |
| `https://claude.ai/*` | Claude 履歴 API へのアクセス |
| `https://gemini.google.com/*` | Gemini 履歴 API へのアクセス |
| `https://www.google.com/*` | GoogleAI 検索結果からの履歴取得 |
| `https://grok.com/*` | Grok 履歴 API へのアクセス |
| `https://x.com/*` | X 内 Grok 履歴の DOM 取得 |

すべての履歴データはローカルの IndexedDB にのみ保存され、外部に送信されません。
